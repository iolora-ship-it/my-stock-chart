# 自分専用 日本株チャートビューア

## 動かし方

1. Python 3.9以上をインストール（未導入の場合）
2. このフォルダで以下を実行

```
pip install -r requirements.txt
streamlit run app.py
```

3. 自動的にブラウザが開き、`http://localhost:8501` でアプリが表示されます。

## スマホ・外出先からも見られるようにする（Streamlit Community Cloud）

無料で公開でき、PCを立ち上げていなくてもスマホのブラウザから見られるようになります。

1. **GitHubアカウントを用意**（持っていなければ https://github.com で無料登録）
2. **GitHubに新しいリポジトリを作成**（例: `my-stock-chart`。Public/Privateどちらでも可）
3. このフォルダの4つのファイル（`app.py` / `stocks.csv` / `requirements.txt` / `README.md`）をそのリポジトリにアップロード
   - GitHubのWeb画面の「Add file → Upload files」からドラッグ&ドロップでOK（コマンド操作不要）
4. https://share.streamlit.io にアクセスし、「Sign in with GitHub」でログイン
5. 「New app」をクリックし、以下を指定
   - Repository: 先ほど作ったリポジトリ
   - Branch: `main`
   - Main file path: `app.py`
6. 「Deploy」をクリック。1〜2分でビルドが完了し、`https://xxxxx.streamlit.app` のようなURLが発行されます
7. スマホでそのURLを開けばOK。ホーム画面に追加しておくとアプリのように使えます

**銘柄を追加・変更したいとき**は、GitHub上の`stocks.csv`を編集して保存（コミット）するだけで、Streamlit Cloud側も自動的に反映されます。

**注意点**
- デフォルトではPublicリポジトリだとアプリのURLを知っている人は誰でも見られます。他人に見られたくない場合は、リポジトリをPrivateにし、Streamlit Cloud側で「Who can view this app」を招待制に設定してください（Streamlitアカウントでのログインが必要になります）。
- yfinanceはYahoo!ファイナンスの非公式データ取得ライブラリのため、クラウド環境からのアクセスが一時的に制限されることがあります。その場合は少し時間を置いて再読み込みしてください。

## できること

- **セクター別比較**: サイドバーでセクターを選ぶと、そのセクター内の銘柄を一覧・比較できます。「セクター」を絞り込まず「すべて」のままだと、デフォルトで表示される銘柄は特定の業種に偏らないよう、各業種から1銘柄ずつ順番に選ばれます（業種をまたいでラウンドロビン方式）。表示銘柄はサイドバーの「銘柄」欄でいつでも変更できます。
- **🌟 プラス材料の多いセクター**: メインダッシュボードに、各セクターの代表銘柄をもとに「📈 トレンド確立・✅ 出来高を伴う陽線・🎯 ルール適合・🏔 52週高値圏・🔍 静かな出来高増加」のうち、いくつのプラス要因バッジが付いているかを集計したランキングを表示します（値動きの平均を見る「🔥 セクターの勢い」とは別の切り口です）。上記のセクター別比較のデフォルト銘柄選択も、業種の登録順ではなくこのランキング順（プラス材料が多いセクター優先）でラウンドロビンされます。通信待ちでサイドバーの表示が遅れないよう、ランキングの計算結果は次回のページ操作時から反映されます。
- **セクター一覧からワンクリックで絞り込み**: 「🔥 セクターの勢い」「🌟 プラス材料の多いセクター」に並ぶ各セクターのカードをクリックすると、サイドバーの銘柄選択がそのセクターに自動的に切り替わります。気になったセクターをすぐに掘り下げて見られます。
- **🗺️ マーケットヒートマップ**: サイドバーの「① どこを見る？」から切り替えられる専用ページ。stocks.csvに登録済みの全銘柄をセクターごとのブロックに並べ、色（期間の騰落率）と大きさ（直近の売買代金の目安）でひと目で値動きを確認できます。色は国内の慣習に合わせて上昇=赤・下落=青（海外ツールは逆配色が多いので注意）。ブロックの大きさは時価総額ではなく売買代金（終値×出来高）の目安にしています（時価総額だと銘柄ごとに別途データ取得が必要になり重くなるため）。登録銘柄数が多いページなので、初回表示には数十秒〜1分程度かかることがあります。
- **🔍 低位株を探す**: 株価が低い・まだ注目されていなさそうな東証銘柄を、候補の出どころを切り替えながら探すページです。サイドバーの「① どこを見る？」から切り替えられます。
  - **🗂 厳選リスト（手動選定）**: stocks.csvとは別の候補リスト（lowprice_stocks.csv）。Yahoo!ファイナンスの「単元株価格下位」「時価総額下位」ランキングを基に、時価総額が極端に小さい銘柄や事業実態の判断が難しいバイオベンチャーなどを除いて手動で選んだ候補リストで、メインダッシュボードと同じ指標・カードUIで確認できます。
  - **🌐 全市場自動スキャン**: stocks.csvやlowprice_stocks.csvに登録している銘柄とは別に、東証の全上場銘柄（ETF・REIT・PRO Marketなどを除く約3,700銘柄）の中から、まだ注目されていなさそうな低位株（株価3,000円以下）を探します。アプリを開いた瞬間にスキャンするのではなく、GitHub Actionsで平日の東証取引終了後（日本時間18時頃）に自動実行されるバッチ処理（`scripts/scan_market.py`）が、前夜までのスキャン結果を`market_scan_results.csv`に書き出し、アプリ側はそれを読み込んで表示する仕組みです（約3,700銘柄をその場でスキャンするのは重すぎるため）。「🔍 静かな出来高増加」「📊 出来高急増」「🆕 新規上場の可能性」の3つのシグナルで絞り込めます。時価総額や事業内容によるスクリーニングは行っていないため、🗂厳選リストよりノイズが多い点にご注意ください。
- **🎯 条件でさがす**: メインの銘柄リストを、選んだ条件でフィルタして表にまとめて確認できるページです。サイドバーの「① どこを見る？」から切り替えられます。
  - **🎯 ルール適合**: サイドバーの「🎯 エントリールール設定」で決めた条件（トレンド確立度・初動の信頼度）を満たす銘柄だけを表で確認できます。バッジだと銘柄を1つずつ開いて確認する必要があり分かりにくいという声を受けて追加しました。
  - **📈 トレンド確立**: エントリールールの設定に関係なく、移動平均線がMA5>MA25>MA75の順に並ぶ「トレンド確立」状態の銘柄だけを、ざっと見渡せる表です。
  - どちらも「低位株・無名株の候補リストも対象に含める」をオンにすると、🗂厳選リスト（lowprice_stocks.csv）の候補も合わせて調べられます（その分時間がかかります）。
- **期間指定のトータル騰落率**: 「5日/10日/20日/60日/半年/1年/カスタム」から期間を選ぶと、前日比ではなく期間全体の騰落率(%)を表示します。表とグラフ両方で確認できます。初期設定は「10日」（5日線と25日線の中間くらいの幅で、初動を拾いつつノイズを均せるバランス）。期間の使い分け方（各期間がチャートのどの移動平均線やバッジと対応するか）は、サイドバーの「③ どの期間で見る？」の下にある「📏 期間の使い分け方」で確認できます。
- **ローソク足チャート**: 個別銘柄を選ぶと日足ローソク足チャートを表示。カーソルを合わせると始値・高値・安値・終値がその場で表示されます。
- **決算発表日の表示**: チャート上にオレンジの点線で決算発表日をマーキングし、直近の決算日一覧もキャプションに表示します（Yahoo!ファイナンスのデータに依存するため、一部銘柄は取得できない場合があります）。
- **大量保有報告書ウォッチ**（要APIキー設定）: 個別チャートページで、5%を超えて保有する大株主の新規報告・変更報告と、提出日の終値からの乖離率を確認できます。
- **利益確定ルール**: サイドバーで「+◯%になったら利益確定する」という目標ラインを設定でき、売買記録タブでルール通りに利確できているかを振り返れます。
- **追加バッジ（決算間近・52週高値圏・信用倍率急増・大量保有報告書・静かな出来高増加）**: 銘柄カードに以下のバッジを表示します。判断に直結するバッジ（トレンド確立度・飛びつき注意など）とは別に、これらは参考情報として「📋 参考情報 他N件」という折りたたみの中にまとめて表示されます（クリックで展開）。
  - 📅 決算間近: 次の決算発表予定日が14日以内に迫っている
  - 🏔 52週高値圏: 現在値が52週高値から5%以内、または更新中
  - 💰 信用買い残急増 / 🏦 大量保有 新規あり（要APIキー設定・任意）: サイドバーの「④ その他の設定」→「🧹 カードの表示設定」で「信用倍率急増・大量保有報告書もチェックする」をオンにすると表示されます（銘柄数が多いページでは表示が遅くなるため初期状態はオフです）。
  - 🔍 静かな出来高増加: 値動きはほとんど変わらないのに出来高だけ普段より増えている銘柄（時価総額500億円以上が対象）に表示されます。機関投資家がこっそり買い集めている可能性がある値動きの目安です。
- **VWMA（出来高加重移動平均線）**: 個別チャートページで「VWMA（20日出来高加重移動平均線）を表示する」をオンにすると、直近20営業日の終値を出来高で重み付けした線をチャートに追加できます。機関投資家が注文執行の基準としてよく使う「VWAP」（1日限定の出来高加重平均）とは別の指標（複数日の移動平均）です。

## 大量保有報告書ウォッチ機能のセットアップ（任意）

個別チャートページで、5%を超えて保有する大株主の新規報告・変更報告（大量保有報告書）を確認できる機能です。
金融庁のEDINET APIを使うため、利用するにはAPIキーの取得と設定が必要です（未設定でも他の機能は問題なく使えます）。

1. [EDINET API仕様書のページ](https://api.edinet-fsa.go.jp/api/v2/) から利用者登録し、APIキー（Subscription-Key）を取得する
2. ローカルで使う場合: `.streamlit/secrets.toml.example` を `.streamlit/secrets.toml` にコピーし、取得したキーを入力する
3. Streamlit Community Cloudで使う場合: アプリの管理画面 → Settings → Secrets に以下を貼り付ける

```
EDINET_API_KEY = "取得したAPIキー"
```

`.streamlit/secrets.toml` は `.gitignore` で除外済みのため、誤ってGitHubにアップロードされることはありません。

## 銘柄の追加・編集

`stocks.csv` を編集するだけで銘柄を追加できます。

```
code,name,sector
7203,トヨタ自動車,輸送用機器
```

- `code`: 証券コード。内部で自動的に `.T` を付けて東証銘柄として取得します（通常4桁ですが、キオクシアのように英字を含む新しいコード形式の銘柄にも対応しています）。
- `sector`: 自由に分類名をつけられます（TOPIX業種区分でなくてもOK）。

主要な日本株444銘柄・46セクターを登録済みです（日経平均株価の採用銘柄や、東証33業種分類ごとの主要企業を中心に随時追加しています）。ご自身のポートフォリオに合わせて自由に書き換えてください。

## 🌐 全市場自動スキャンバッチの仕組み（GitHub Actions）

「🔍 低位株を探す」ページの「🌐 全市場自動スキャン」は、`scripts/scan_market.py`というバッチ処理の結果を表示しているだけで、アプリ自体はこのスキャンを実行しません。

- **実行タイミング**: `.github/workflows/market_scan.yml`により、平日（月〜金）のUTC 9:00（日本時間18:00、東証の取引終了後）に自動実行されます。GitHubリポジトリの「Actions」タブから手動実行（workflow_dispatch）することもできます。
- **処理内容**: JPXが毎月更新している「東証上場銘柄一覧」（`data_j.xlsx`）を都度ダウンロードして最新の上場銘柄一覧を取得し、ETF・ETN・REIT・PRO Marketなどを除いた約3,700銘柄のうち株価3,000円以下の銘柄を対象に、「静かな出来高増加」「出来高急増」「新規上場の可能性」の3シグナルを判定します。該当した銘柄だけを`market_scan_results.csv`に書き出し、変化があればリポジトリに自動コミットします。
- **実行結果の確認・失敗時**: リポジトリの「Actions」タブから実行ログを確認できます。yfinance側の一時的な取得失敗などでバッチが失敗した場合でも、アプリ側は前回までの結果ファイルをそのまま表示し続けます（アプリが落ちることはありません）。
- **既知の限界**: 新規上場の判定は、銘柄ごとに正確な上場日を取得する代わりに「取得できる価格データの長さ」を目安にしているため、データが取得しづらいだけの銘柄も同じ判定になることがあります。また、低位株ページの候補リストとは異なり、時価総額や事業内容（赤字バイオベンチャーなど）によるスクリーニングは行っていません。

## 既知の制約

- 株価データは Yahoo!ファイナンス（yfinance経由）を利用しているため、取得タイミングにより15〜20分程度の遅延がある場合があります。
- 決算日データは銘柄によって取得できないことがあります。
- 大量の銘柄を一度に選択すると初回読み込みに時間がかかります（2回目以降は10分間キャッシュされます）。
- 「🔍 低位株を探す」ページの「🌐 全市場自動スキャン」は、GitHub Actionsの夜間バッチが初回実行されるまで結果が空の状態です。
